# 11 — 按键控制与 UI 功能列表

## 设计目标

定义所有玩家操作的按键映射和全部 UI 面板的功能清单。本文档为输入系统和 UI 开发提供统一的参考基准。

---

## 输入系统

基于 UE5 Enhanced Input 系统，所有操作通过 Input Action 定义，支持键盘/鼠标和手柄双输入。

### 按键约定

| 表示 | 含义 |
|------|------|
| `[K]` | 键盘 |
| `[M]` | 鼠标 |
| `[G]` | 手柄 (Xbox 布局) |
| `Hold` | 长按 |
| `Double` | 双击 |
| `Tap` | 短按/点按 |

---

## 飞船操控

玩家驾驶飞船时的全部操作。飞船采用 6-DOF（六自由度）飞行模型。

### 移动

| 操作 | 键盘/鼠标 | 手柄 | 说明 |
|------|----------|------|------|
| 前进/后退 | `[K] W / S` | `[G] 左摇杆 Y` | 主推进器推力 |
| 左右平移 | `[K] A / D` | `[G] 左摇杆 X` | 侧推进器 |
| 上升/下降 | `[K] Space / LeftCtrl` | `[G] LB / RB` | 垂直推进器 |
| 俯仰 | `[K] 鼠标 Y` | `[G] 右摇杆 Y` | 机头上下 |
| 偏航 | `[K] 鼠标 X` | `[G] 右摇杆 X` | 机头左右 |
| 翻滚 | `[K] Q / E` | `[G] 左右摇杆按下 + X` | 绕纵轴旋转 |

### 飞行模式

| 操作 | 键盘/鼠标 | 说明 |
|------|----------|------|
| 常规推进 | 默认 | 星系内低速飞行、战斗机动 |
| 巡航模式 | `[K] Shift (Hold)` | 行星间高速航行，转向受限 |
| 曲速航行 | `[K] F (Hold)` | 跨星系 FTL，需先选择目标星系 |
| 紧急制动 | `[K] Space + LeftCtrl` | 全推力反向减速，短时高油耗 |
| 惯性滑行 | `[K] Z (Tap)` | 关闭引擎，保持当前速度惯性飞行 |
| 速度匹配 | `[K] X (Tap)` | 自动匹配锁定目标的速度 |

### 战斗操作

| 操作 | 键盘/鼠标 | 说明 |
|------|----------|------|
| 锁定目标 | `[K] 鼠标中键 (Tap)` | 锁定准星指向的敌船 |
| 切换锁定目标 | `[K] Tab` | 在视野内敌船间循环切换 |
| 选择子系统 | `[K] 1/2/3/4` | 引擎/武器/护盾/反应堆 |
| 主武器开火 | `[K] 鼠标左键` | 当前选中的第一武器组 |
| 副武器开火 | `[K] 鼠标右键` | 当前选中的第二武器组（如导弹） |
| 切换武器组 | `[K] R` | 循环切换已安装的武器组 |
| 电力分配面板 | `[K] Ctrl` | 战斗中动态调配电力到引擎/护盾/武器 |

### 扫描与探索

| 操作 | 键盘/鼠标 | 说明 |
|------|----------|------|
| 被动扫描 | 自动 | 进入星系自动获取基本信息 |
| 主动扫描脉冲 | `[K] V (Tap)` | 探测资源分布和信号源 |
| 近距离扫描 | `[K] V (Hold)` | 锁定目标时获取详细数据 |

### 飞船内操作

| 操作 | 键盘/鼠标 | 说明 |
|------|----------|------|
| 离开驾驶位 | `[K] E (Hold)` | 从驾驶舱起身，切换到舱内行走模式 |
| 对接/登船 | `[K] E (Tap)` | 靠近对接目标时触发对接 |
| 打开星图 | `[K] M` | 查看和规划航行路线 |

## 舱内行走

玩家在飞船内部或遗迹/空间站内以第三人称行走时的操作。

### 移动与视角

| 操作 | 键盘/鼠标 | 手柄 |
|------|----------|------|
| 移动 | `[K] WASD` | `[G] 左摇杆` |
| 视角 | `[K] 鼠标` | `[G] 右摇杆` |
| 奔跑 | `[K] Shift (Hold)` | `[G] 左摇杆按下` |
| 蹲伏 | `[K] LeftCtrl (Tap)` | `[G] B` |
| 跳跃/攀爬 | `[K] Space` | `[G] A` |
| 上下梯子 | `[K] W/S` | `[G] 左摇杆 Y` |

### 交互

| 操作 | 键盘/鼠标 | 说明 |
|------|----------|------|
| 交互（使用设施） | `[K] E (Tap)` | 制造台/储物柜/医疗站/睡眠舱 |
| 拾取物品 | `[K] F (Tap)` | 拾取地上的散落物品 |
| 打开背包 | `[K] Tab` | 查看和管理物品 |
| 手电筒 | `[K] T` | 开关头盔/手持光源 |
| 切换工具 | `[K] 鼠标滚轮` | 手持工具之间切换 |
| 使用当前工具 | `[K] 鼠标左键` | 切割/修理/扫描等 |
| 快速医疗 | `[K] H (Tap)` | 使用背包中的急救包（优先使用最低级） |

### 战斗

| 操作 | 键盘/鼠标 | 说明 |
|------|----------|------|
| 瞄准 | `[K] 鼠标右键 (Hold)` | 举枪瞄准 |
| 射击 | `[K] 鼠标左键` | 当前装备的武器开火 |
| 切换武器 | `[K] 1/2/3` | 主武器/副武器/近战工具 |
| 换弹 | `[K] R` | 装填弹药 |
| 近战攻击 | `[K] V` | 枪托/切割工具攻击 |

## 建造模式

玩家在建造飞船模块和舱内设施时的操作。

### 飞船模块建造

| 操作 | 键盘/鼠标 | 说明 |
|------|----------|------|
| 进入建造模式 | `[K] B (Tap)` | 需靠近飞船技师或基地终端 |
| 选择模块 | `[K] 鼠标左键` | 从模块列表中选择 |
| 放置模块 | `[K] 鼠标左键` | 在有效连接点放置 |
| 旋转模块 | `[K] R` | 90 度旋转（仅基础模块可旋转） |
| 删除模块 | `[K] Delete / 鼠标右键` | 指向已放置模块删除 |
| 撤销 | `[K] Ctrl+Z` | 撤销上一步操作 |
| 重做 | `[K] Ctrl+Y` | 重做被撤销的操作 |
| 飞行检查 | `[K] Enter` | 运行建造验证，显示错误/警告 |
| 确认保存 | `[K] Enter (Double)` | 飞行检查通过后确认保存 |
| 退出建造 | `[K] Escape` | 退出建造模式（未保存的修改丢失） |
| 蓝图模式 | `[K] Ctrl+B` | 切换到蓝图模式（先规划后建造） |

### 舱内设施放置

| 操作 | 键盘/鼠标 | 说明 |
|------|----------|------|
| 进入设施模式 | `[K] B (Tap)` | 在舱内行走时切换到设施放置 |
| 选择设施 | `[K] 鼠标左键` | 从设施列表中选择 |
| 移动预览 | `[K] 鼠标` | 在三维空间中移动半透明预览 |
| 翻转/旋转 | `[K] R` | 改变设施朝向 |
| 贴附切换 | `[K] Tab` | 切换支撑面：地板/墙壁/天花板 |
| 确认放置 | `[K] 鼠标左键` | 绿色预览 = 可放置 |
| 取消放置 | `[K] 鼠标右键 / Escape` | 取消当前放置操作 |
| 拆除设施 | `[K] Delete` | 指向已放置设施拆除 |

### 内部布局（门/梯子）

| 操作 | 键盘/鼠标 | 说明 |
|------|----------|------|
| 放置门 | `[K] G (Tap)` | 在相邻舱室连接面放置门 |
| 放置梯子 | `[K] L (Tap)` | 在上下层舱室之间放置梯子 |
| 内部预览 | `[K] P (Hold)` | 展示内部通道连通情况 |

## UI 面板列表

全部 UI 面板按功能模块分类。

### 常驻 HUD

| 面板 | 显示内容 | 显示条件 |
|------|----------|----------|
| 飞船状态栏 | 船体完整性、护盾值、电力剩余、当前速度 | 驾驶飞船时始终显示 |
| 目标信息 | 锁定目标名称、距离、护盾/船体状态 | 锁定目标时显示 |
| 武器状态 | 当前武器组、弹药余量、冷却状态 | 驾驶飞船时始终显示 |
| 生存指标 | O2、生命值、温度、辐射 | 舱内行走时始终显示（精简版：O2 + HP） |
| 小地图/雷达 | 周边天体、信号源、敌舰位置 | 驾驶飞船时始终显示 |
| 交互提示 | "按 E 交互" / "按 F 拾取" | 靠近可交互对象时显示 |
| 通知横幅 | 事件提示（"收到新信号" / "船体受损"） | 事件触发时短暂显示 |

### 主菜单面板

| 面板 | 功能 | 打开方式 |
|------|------|----------|
| 背包 | 查看/整理物品、装备工具、使用消耗品 | `Tab` |
| 星图 | 查看已知星系、规划航线、放置标记 | `M` |
| 科技树 | 浏览科技领域、投入科学点研究、查看解锁条件 | `T` |
| 飞船建造器 | 模块列表、飞行检查面板、属性预览 | 靠近飞船技师 + `B` |
| 基地建造器 | 模块列表、约束检查面板 | 靠近基地终端 + `B` |
| 设计图集 | 查看已解锁的设计图、浏览收藏 | `J` |
| 任务/日志 | 叙事线索记录、已发现数据日志、当前目标追踪 | `L` |
| 派系面板 | 各派系好感度、交易优惠、敌对状态 | `P` |
| 设置菜单 | 画面/音频/控制/游戏设置 | `Escape` |
| 存档管理 | 保存/加载/删除存档 | 设置菜单内 |

### 交互界面

| 界面 | 功能 | 触发条件 |
|------|------|----------|
| 制造台界面 | 选择配方 → 放入材料 → 制造 | 走到制造台前按 `E` |
| 储物柜界面 | 存取物品 | 走到储物柜前按 `E` |
| 医疗站界面 | 选择治疗类型 → 确认治疗 | 走到医疗站前按 `E` |
| 飞船技师界面 | 升级模式 + 自由建造入口 | 与飞船技师 NPC 对话 |
| 贸易界面 | 买卖物品，显示价格和数量 | 与商人 NPC 对话 |
| 对话界面 | 对话选项、派系好感变化预览 | 与 NPC 对话时 |
| 数据日志阅读 | 阅读找到的文本日志 | 拾取日志时自动弹出或从任务面板打开 |
| 全息终端 | 阅读/播放全息信息 | 在遗迹中找到终端并激活 |

### 提示与确认

| 面板 | 功能 |
|------|------|
| 工具提示 (Tooltip) | 鼠标悬停物品/模块时显示名称、属性、配方 |
| 确认对话框 | 删除模块/覆盖存档/放弃建造等破坏性操作前确认 |
| 进度条 | 大型模块建造进度、FTL 航行进度、制作进度 |
| 教学提示 | 首次遇到新系统时显示操作指引 |
| 警告弹窗 | 船体严重受损、生命支持即将耗尽、辐射超标等紧急警告 |
