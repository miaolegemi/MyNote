# 10 — 开发计划

## 文档目标

将设计文档转化为可执行的开发路线图。定义各阶段的交付物、依赖关系、时间估算和风险对策。

**使用方式：** 每个阶段开始前，团队基于本文档进行冲刺规划（Sprint Planning），将阶段目标拆解为具体任务。

---

## 总体路线

```
原型验证 ──→ 垂直切片 ──→ 核心系统 ──→ 内容填充 ──→ 深度打磨 ──→ 终局 ──→ 打磨发布
  (~3月)     (~6月)      (~6月)      (~6月)      (~4月)     (~3月)     (~3月)

                          ← 约 31 个月 →
```

**总预估周期：** 2.5 年（30 人核心团队基准，可按团队规模调整）

---

## 阶段一：原型验证

**目标：** 验证核心循环（建造 → 飞行 → 登舰/登陆探索 → 返回）是否好玩。回答最根本的问题：这个游戏值得做吗？

**时间：** ~3 个月

### 交付物

| 功能 | 说明 | 验收标准 |
|------|------|----------|
| 飞船建造（基础） | 驾驶舱 + 引擎 + 货舱 + 基础走廊的放置与拼接 | 能自由拼出一艘能通过飞行检查的飞船 |
| 飞行手感 | 6-DOF 飞行，常规推进 + 巡航模式 | 转向、加速、减速手感可接受；能在小行星带中穿行 |
| 基础生存 | O2 + HP 两个指标，O2 耗尽死亡 | O2 消耗/补充循环正常运作 |
| 采矿（基础） | 用采矿激光从小行星采集铁矿石 | 锁定 → 开采 → 矿石进入货舱 |
| 舱内行走 | 在飞船内部行走，与设备互动 | 能在飞船内部自由移动，操作制造台/储物柜等设备 |
| 建造验证 | 飞行检查（必备模块 + 电力预算 + 质量推力比） | 不通过时高亮问题模块 |
| 测试星系 | 1 个手工搭建的星系（恒星 + 2-3 行星 + 小行星带） | 稳定运行，帧率 > 60fps |

### 不做的事

- 不做基地建造（仅飞船）
- 不做 FTL / 跨星系
- 不做战斗
- 不做科技树和设计图
- 不做完整的生存系统（食物/水/温度/辐射）
- 不做程序化生成

### 关键风险

- 建造系统的网格/吸附机制是否直观
- 太空飞行手感的玩家接受度
- 6-DOF 是否导致玩家迷失方向

### 交付决策点

原型验证结束时召开**评审会议**，由核心团队试玩并投票是否进入下一阶段。不通过则回到设计层面调整，不硬推进。

## 阶段二：垂直切片

**目标：** 完成单星系内的完整游戏循环——一条功能完整的玩法链条，从头到尾可玩。

**时间：** ~6 个月

### 系统拆解

#### 2A. 建造系统完善（~2 个月）

| 功能 | 依赖 | 验收标准 |
|------|------|----------|
| 完整飞船模块（7 类） | 阶段一建造基础 | 每种模块可放置、可运作 |
| 建造验证完整版 | 模块属性数据 | 全部硬性错误 + 软性警告生效 |
| 电网系统 | 反应堆 + 用电模块 | 电力优先级、动态分配、超载降级 |
| 生命支持系统 | 密封模块 | O2 消耗/补充、温控、人数限制 |
| 蓝图模式 | 建造器 | 可先规划布局再确认建造 |
| 撤销/回退 | 建造器 | 放置后可按 Z 撤销 |
| 基地建造（基础） | 空间站模块 | 指挥中心 + 熔炉 + 居住舱可拼接 |

#### 2B. 采集与制造（~1.5 个月）

| 功能 | 依赖 | 验收标准 |
|------|------|----------|
| 完整资源层级（T1-T2） | 采矿系统 | 矿石 → 材料 的完整加工链 |
| 基础熔炉 + 化学处理站 | 基地/飞船能源 | 放置 → 供电 → 放入原料 → 产出材料 |
| 制作系统 | 配方数据库 | 消耗品 + 工具 + 基础模块可制造 |
| 货舱管理 | 库存系统 | 容量限制、超重影响飞行速度 |

#### 2C. 探索与扫描（~1 个月）

| 功能 | 依赖 | 验收标准 |
|------|------|----------|
| 扫描系统（被动 + 主动 + 近距离） | 星系数据 | 三级扫描信息逐步解锁 |
| 星图界面 | 星系数据 | 已发现天体可视化、自定义标记 |
| 兴趣点（基础） | 星系内据点模板 | 废弃前哨站 A/B/C 可发现、可进入 |

#### 2D. 基础战斗（~1 个月）

| 功能 | 依赖 | 验收标准 |
|------|------|----------|
| 舰船锁定与射击 | 武器模块 | 锁定 → 开火 → 伤害结算 |
| 护盾系统 | 护盾模块 | 吸收伤害、再生、过载 |
| 基础 AI（海盗拦截） | 敌船配置 | 拦截 → 索要货物 → 不满即攻击 |
| 潜行（信号管理） | 引擎/系统控制 | 关引擎 → 信号降低 → 更难被发现 |

#### 2E. 整合（~0.5 个月）

- 所有系统在单个星系内串联：建造飞船 → 飞出空间站 → 扫描信号 → 采集资源 → 遭遇海盗 → 返航制造 → 扩建飞船
- **垂直切片演示**：录制 15 分钟无剪辑游玩视频

### 不做的事

- 不做跨星系 FTL
- 不做科技树
- 不做叙事
- 不做自动化

## 阶段三：核心系统

**目标：** 多星系宇宙、FTL 航行、完整进度系统——游戏从现在开始有"内容广度"。

**时间：** ~6 个月

### 系统拆解

#### 3A. 宇宙扩展（~2 个月）

| 功能 | 依赖 | 验收标准 |
|------|------|----------|
| 程序化星系生成 | 种子系统 | 20-30 个星系，每次新游戏一致 |
| 天体物理参数推算 | 星系种子 | 温度、重力、大气成分基于物理规则 |
| PCG 地形 | UE PCG 框架 | 行星表面可登陆、可行走 |
| 资源分布规则 | 天体参数 | 近恒星→稀有矿物多，特定环境产出特定资源 |
| 流式加载 | 玩家位置 | 远近 LOD 切换流畅，无加载画面 |
| FTL 航行（曲速 + 跳跃） | 跨星系坐标 | 选择目标 → 曲速航行（含航行事件）→ 到达 |
| 航线事件 | FTL 系统 | 信号中断、引力异常、海盗拦截、求救信号 |

#### 3B. 进度系统（~1.5 个月）

| 功能 | 依赖 | 验收标准 |
|------|------|----------|
| 科技树（6 领域） | UI + 数据配置 | 科学点投入 → 解锁科技 → 获得设计图 |
| 科学研究系统 | 扫描系统 | 扫描获得科学点，实验室提高效率 |
| 设计图系统 | 科技树 + 野外发现 | 完整设计图 + 碎片拼合 |
| 里程碑追踪 | 事件总线 | 建造/探索/战斗里程碑自动检测并触发解锁 |
| 建造驱动进度 | 建造事件 | "第一个分析实验室"等 8 个关键节点生效 |

#### 3C. 资源经济完善（~1 个月）

| 功能 | 依赖 | 验收标准 |
|------|------|----------|
| Tier 3 资源 | 深空区域 | 稀有材料仅在危险区域产出 |
| 精密加工台 + 高级装配线 | 基地能源 | 高级组件制造 |
| 回收站 | 库存 | 拆解残骸/旧模块回收材料 |
| 耐久与维修 | 物品系统 | 工具/模块使用消耗耐久，修理消耗材料 |

#### 3D. 基地建造完善（~1 个月）

| 功能 | 依赖 | 验收标准 |
|------|------|----------|
| 完整基地模块（7 类） | 阶段二基地基础 | 全部模块可建造 |
| 基地建造约束 | 生命支持/电力/地基 | 超限无法保存 |
| 环境加固 | 高危环境 | 辐射行星需要额外加固模块 |
| 船坞功能 | 基地船坞模块 | 飞船修理、模块升级 |

#### 3E. 生存系统完善（~0.5 个月）

| 功能 | 依赖 | 验收标准 |
|------|------|----------|
| 食物/水/温度/辐射 | 生存指标框架 | 全部二级指标生效 |
| 伤病系统 | 生存事件 | 轻/中/重伤治疗链 |
| 状态效果 | 环境触发 | 低温症、辐射病、缺氧、疲劳 |

## 阶段四：内容填充

**目标：** 世界变得有血有肉——手工艺 POI、叙事弧启动、派系交互。

**时间：** ~6 个月

### 系统拆解

#### 4A. 兴趣点与遗迹（~2.5 个月）

| 功能 | 依赖 | 验收标准 |
|------|------|----------|
| 废弃空间站（8 种变体） | POI 模板系统 | 各具独特的布局、日志、战利品 |
| 外星遗迹（4 处核心） | 手工艺设计 | 每处包含谜题、敌人、叙事数据 |
| 海盗据点（5 种变体） | 战斗系统 | 可潜入或正面攻打 |
| 其他 POI 类型 | 模板投放 | 求救信标、资源富集点、虫洞、远古舰坟场 |
| POI 投放规则 | 星系种子 | 每个星系有合理密度的兴趣点 |

#### 4B. 叙事系统（~1.5 个月）

| 功能 | 依赖 | 验收标准 |
|------|------|----------|
| 线索网管理 | 叙事数据 | 线索碎片收集 → 拼合 → 推进叙事弧 |
| 叙事弧一（信号） | 扫描 + 遗迹 | 追踪信号 → 发现第一个外星遗迹 |
| 叙事弧二（碎片） | 多个遗迹 | 跨星系收集数据碎片拼出历史片段 |
| 环境叙事分发 | POI 系统 | 数据日志、音频日志、视觉叙事 |
| 派系关系 | 好感度系统 | 6 个派系的好感度影响交易/通行/敌对 |

#### 4C. 战斗深度（~1.5 个月）

| 功能 | 依赖 | 验收标准 |
|------|------|----------|
| 子系统瞄准 | 锁定系统 | 攻击引擎/武器/护盾/反应堆各有不同效果 |
| 电源战术 | 电网系统 | 战斗中动态分配电力 |
| 登船 | 对接系统 | 瘫痪敌船引擎 → 对接 → 进入敌船 |
| 完整 AI 行为框架 | AI 系统 | 领地防御、劫掠、猎食、复仇、恐惧 |
| 登舰/舱内战斗 | 角色控制 | 手枪/步枪/切割工具，零重力环境 |

#### 4D. 环境危险（~0.5 个月）

| 功能 | 依赖 | 验收标准 |
|------|------|----------|
| 辐射带 | 辐射系统 | 进入后辐射持续累积 |
| 陨石雨 | 物理系统 | 随机伤害船体 |
| 太阳耀斑 | 恒星距离 | 电子设备故障、护盾击穿 |
| 引力阱 | 物理系统 | 引擎过载、油耗增加 |
| 电磁风暴 | 传感器系统 | 传感器失灵、HUD 故障 |

## 阶段五：深度打磨

**目标：** 战斗变得有深度，AI 行为可信，程序化生成质量达标。

**时间：** ~4 个月

| 功能 | 说明 |
|------|------|
| Boss 遭遇（4 个） | 星噬者、海盗无畏舰、远古守护者、企业追捕舰队 |
| AI 行为打磨 | 各行为类型的决策树调优、难度曲线 |
| POI 模板扩展 | 每种类型增加更多变体，减少重复感 |
| 程序化生成调优 | 地形质量、资源分布合理性、生物群落多样性 |
| 经济平衡 | 资源产出/消耗曲线、交易价格、制造时长全面校准 |
| 难度曲线 | 从起始星系到深空的难度递增是否平滑 |
| 体验测试 | 组织外部玩家测试，收集反馈 |

## 阶段六：终局

**目标：** 叙事弧三/四、自动化、终局方向——给深度玩家长期目标。

**时间：** ~3 个月

| 功能 | 说明 |
|------|------|
| 叙事弧三（星门） | 发现并激活外星星门，到达未知星系 |
| 叙事弧四（真相） | 最深遗迹揭示"他们去哪了" |
| 自动化系统 | 管道/传送带/无人机/自动制造 |
| 远古遗迹完整版 | 激活后解锁终极设计图 |
| 终局方向 | 远古之谜、星际大亨、终极飞船、归乡 |
| 量子锻造炉 | Tier 4 异星材料处理 |

## 阶段七：打磨发布

**目标：** 性能、UI、音频、本地化——成为可发布产品。

**时间：** ~3 个月

| 功能 | 说明 |
|------|------|
| 性能优化 | 大型飞船/基地的帧率、PCG 流式加载的卡顿、GPU/内存预算 |
| UI 打磨 | HUD 信息层级、建造界面易用性、星图导航体验、手柄适配 |

| 稳定性 | 崩溃修复、存档兼容性、边界情况覆盖 |
| 宣传物料 | 预告片、截图、商店页面 |

## 系统依赖关系

```
阶段一          阶段二            阶段三              阶段四          阶段五/六
──────────────────────────────────────────────────────────────────────────────

飞船建造 ────→ 完整建造 ────→ 基地完善 ────→ 自动化
  │              │               │
  ├→ 飞行手感    ├→ 电网系统     ├→ PCG 星系 ──→ POI 投放 ──→ 程序化调优
  │              │               │               │
  ├→ 基础生存 ──→ 生存完善      ├→ FTL 航行 ──→ 航线事件
  │              │               │
  └→ 采矿 ────→ 制作系统 ──→ 资源经济 ──→ 耐久维修
                 │               │
                 ├→ 基础战斗 ──→ 战斗深度 ──→ Boss
                 │               │
                 ├→ 扫描系统 ──→ 科技树 ────→ 设计图
                 │               │
                 └→               └→ 派系关系 ──→ 叙事系统 ──→ 终局叙事
```

### 关键依赖链

| 前置 | 后置 | 为什么必须按顺序 |
|------|------|-----------------|
| 飞船建造 | 电网系统 | 电力是模块的属性，没有建造系统就无法验证电力逻辑 |
| 采矿 | 制作系统 | 制作消耗材料，材料来自采集 |
| 扫描 | 科技树 | 科学点来自扫描和分析 |
| 电网 | 战斗深度 | 战斗中动态电力分配需要电网系统先运作 |
| FTL | 多星系内容 | 只有能跨星系，才需要做第二个星系的内容 |
| PCG 星系 | POI 投放 | POI 投放依赖星系种子和天体参数 |

## 风险与对策

| 风险 | 严重度 | 概率 | 对策 |
|------|--------|------|------|
| 建造系统手感不佳 | 致命 | 中 | 原型阶段就验证。准备多种网格方案备选（自由吸附/严格网格/混合） |
| 太空 6-DOF 导致玩家迷失 | 高 | 中 | 提供自动水平校正、HUD 方位指示、一键回正 |
| 程序化生成质量不达标 | 高 | 中 | 手工艺 + 模板化为主，PCG 仅填充地形和基础资源分布 |
| 流式加载卡顿 | 高 | 中 | 尽早建立性能预算，大型 POI 使用单独的加载策略 |
| 飞船模块太多导致验证性能问题 | 中 | 低 | 增量验证 + 200 模块上限。架构上已有 <100ms 目标 |
| 内容量不足 | 中 | 高 | 优先保障手工艺 POI 的质量而非数量。模板化 POI 增加变体 |
| 生存系统过于繁琐 | 中 | 中 | 可配置的难度选项；确保"刚好够"而不是"一直不够" |
| 战斗深度不足（与"探索>战斗"支柱矛盾） | 中 | 低 | 战斗不追求复杂度，追求"有意义的抉择"（子系统瞄准、电力分配） |
| 叙事与沙盒冲突 | 中 | 中 | 保持叙事"可随时中断"，不强制推进。线索驱动而非任务驱动 |
| 团队规模不足 | 致命 | 中 | 砍内容广度保深度：减少星系数量、减少模块类型、推迟自动化 |

## 冲刺节奏建议

每个阶段内部按 **3 周一冲刺** 的节奏执行：

```
第 1 周                    第 2 周                    第 3 周
─────────────────    ─────────────────    ─────────────────
Sprint Planning       开发 + 每日站会       开发 + 每日站会
开发 + 每日站会      （不引入新任务）       周五：Sprint Review
                                             + Retrospective
```

- **Sprint Planning**：从阶段交付物中选取本冲刺目标，拆解为每人可完成的任务
- **Daily Standup**：每人 1 分钟——昨天做了什么、今天做什么、有什么卡住
- **Sprint Review**：演示本冲刺完成的功能，与验收标准对照
- **Retrospective**：什么做得好、什么需要改进、下个冲刺的行动项
