# 12 — 核心系统详细设计

## 设计目标

本文档从 `09-程序框架设计` 中拆分而来，详细描述 8 大核心系统的技术架构、关键接口和数据结构。**所有系统均处于规划阶段**，尚未在代码中实现。

系统交互拓扑、事件总线等系统间通信机制参见 `09-程序框架设计`。

```
      ├── URadiationSicknessEffect         // 生命上限降低（I/II/III 三级）
      ├── UHypoxiaEffect                   // 视野收窄、操作精度下降
      ├── UDecompressionEffect             // 听力模糊、视野震荡（30s 恢复）
      └── UFatigueEffect                   // 操作速度-15%

// ── 伤病 ──
UObject
 └── UInjury
      ├── EInjurySeverity Severity          // Minor/Moderate/Severe/Permanent
      ├── virtual void ApplyEffects(UVitalSignComponent* Target)
      └── virtual void Heal(UHealingItem* Item)

// ── 船体破损与减压 ──
UObject
 └── UHullBreachSystem
      ├── void OnModuleBreached(ABuildableActor* Module)
      │    // 舱壁破裂 → 该舱室急速失压 → O2 极速流失
      └── void SealCompartment(ABuildableActor* Module)
           // 关闭防水门隔离受损舱段
```

**数据流：**
```
每 1 秒:
    USurvivalManager::Tick(DeltaTime)
        → for each UVitalSignComponent in World:
            → 基于当前环境计算消耗率
                ├── IsInSealedEnvironment？ → 低消耗
                ├── IsInBreachedCompartment？ → 高消耗（急速失压）
                └── IsInHazardZone？ → 额外消耗（辐射/温度/有毒大气）
            → 更新各项指标
            → 检查阈值
                ├── O2 < 30% → FireEvent("O2Warning")
                ├── O2 < 10% → FireEvent("O2Critical")
                ├── Health <= 0 → FireEvent("PlayerDeath")
                └── Radiation > Threshold → ApplyStatusEffect(URadiationSicknessEffect)
```
