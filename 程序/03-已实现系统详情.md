## 1. 电力网络系统

采用**普通 C++ 类**（非 UObject），通过链表和信号标志实现灵活的电力传输与逻辑控制。

```
ElectricManager                          // 管理器（非 UObject，手动管理生命周期）
 ├── TSet<FElectricNode*> ElectricNodes  // 所有节点集合
 ├── FElectricNode* AddNode(...)         // 创建并注册节点
 ├── void RemoveNode(FElectricNode*)     // 移除节点
 └── void Tick()                         // 每帧驱动: Transfer() → PrepareNextPeriod()

FElectricNode                            // 电力网络节点（普通 C++ struct）
 ├── float InputPower                    // 本帧输入功率
 ├── float MaxInputPower                 // 过载保护阈值（默认 9999）
 ├── float Capacity / MaxCapacity        // 电池（缓存多余功率）
 ├── float ConsumePower                  // 自身消耗
 ├── ELESignalFlag SignalFlag            // 输出信号标志
 ├── ELESignalFlag WorkFlag              // 当前工作信号
 ├── FElectricNode* LinkedNode           // 下游节点（单向链表）
 ├── void Transfer()                     // 传输逻辑: 信号判断 → 过载检测 → 电池充放 → 传递
 └── void PrepareNextPeriod()            // 周期重置: InputPower → BeforeInput, 清除标志
```

**信号标志 (ELESignalFlag)** — 布尔逻辑路由：
```
None | NoContains | Not | Or1 | Or2 | And1 | And2 | Xor1 | Xor2
```
- 使用 `ENUM_CLASS_FLAGS` 支持位运算
- `Transfer()` 中通过 `EnumHasAllFlags`/`EnumHasAnyFlags` 判断节点是否通电
- 信号随功率沿网络传播：上游输出 → `|=` 写入下游 `WorkFlag`

**器具链表 (AApplianceActor)**：继承自 `AInteriorFacilityActor`
```
AApplianceActor : AInteriorFacilityActor
 ├── InNode / InNode2 / OutNode / OutNode2  // 最多 4 个电力节点
 ├── ParentAppliance / ChildAppliance        // 链表结构（单数命名）
 ├── TempTail                         // 尾部追踪临时指针
 ├── float ConsumePower               // 电力消耗
 ├── virtual void IniElectricNode()   // 子类重写：创建专属电力节点
 ├── virtual AApplianceActor* GetTail()
 ├── virtual void TailChanged(AApplianceActor* NewTail)
 ├── void Linked()                    // 链接到电力链
 └── void SetNoCableLink(FElectricNode* TargetNode)  // 无线直连
```

**设计要点：**
- 非 UObject 设计适合高频 Tick（避免 GC 开销），但需注意**手动内存管理**——`AddNode` 用 `new` 分配，目前无对应的 `delete`
- 信号标志系统让电力网络支持"条件通电"——如"仅当引擎启动且武器未过热时，护盾增强器才通电"
- 链表结构支持器具串联：电源 → 反应堆 → 配电板 → 各设备

## 2. 物品与库存系统

采用**片段模式 (Fragment Pattern)**——组合优于继承，类似 UE Lyra 的物品系统。

**数据定义层（USTRUCT，编译期静态数据）：**

```
FTableRowBase
 └── FItemTableRow                         // DataTable 行（策划配置）
      ├── int ID                           // 唯一标识
      ├── int MaxNum                       // 最大堆叠数
      ├── int Durability                   // 耐久度
      └── TArray<FInstancedStruct> Fragments  // 片段数组
           // 元数据: BaseStruct=FItemFragment, ExcludeBaseStruct
           // 可选子类: FItemFragment_Display, (未来扩展: _Equippable, _Usable, ...)

FItemFragment (USTRUCT, BlueprintType)
 └── FItemFragment_Display                 // 显示片段
      ├── FString Name                     // 物品名
      └── FString Desc                     // 物品说明
```

**运行时实例层（UObject，运行时状态）：**

```
UActorComponent
 ├── UInventoryComponent                   // 库存容器组件（挂载到 Pawn / 飞船 / 容器 Actor）
 │    ├── int Capacity                     // 最大槽位数
 │    ├── TArray<UItemInstance*> Items     // 物品实例数组
 │    ├── bool AddItem(int ItemId, int Num)  // 添加（自动堆叠）
 │    ├── UItemInstance* RemoveItemAt(int Idx) // 移除
 │    ├── bool ExchangeItem(...)           // 跨组件交换/合并
 │    └── int GetItemNum(int ItemId)       // 统计某物品总数
 │
 └── UItemInstance                         // 物品运行时实例
      ├── int64 ID                         // 模板 ID（对应 FItemTableRow::ID）
      ├── int64 Num                        // 堆叠数量
      ├── TSubclassOf<FItemTableRow> DefData  // 注意：TSubclassOf 用于 USTRUCT 可能有问题
      └── static CreateItem(UInventoryComponent*, int Index, int ItemId, int Num)  // 工厂方法
```

**已实现：** 添加/移除/交换/统计 | **未实现：** 同ID堆叠、物品使用效果、数据查找（`GetItemData` 返回 nullptr）

## 3. 交互系统

基于视锥检测的通用交互系统。通过接口 + 组件的模式分离检测与行为。

**接口与组件：**
```
UInterface
 └── IInteractableInterface                   // 接口
      ├── bool OnInteract(AActor* Instigator)      // 触发交互
      ├── FText GetInteractPrompt() const          // 获取提示文本
      └── bool IsInteractable() const              // 是否可交互

UActorComponent
 ├── UInteractableComponent : IInteractableInterface  // 可交互组件
 │    ├── FText InteractionPrompt                       // 提示文本
 │    ├── bool bEnabled                                 // 启停开关
 │    └── FOnInteract OnInteractDelegate                // 交互事件广播
 │
 └── UInteractionComponent                              // 交互检测组件
      ├── float InteractRange = 300.0f                  // 检测范围
      ├── float InteractAngle = 45.0f                   // 检测角度（度）
      ├── TScriptInterface<IInteractableInterface> CurrentInteractable  // 当前目标
      ├── void BindInput(UInputComponent*)              // 绑定交互输入
      ├── void Interact()                               // 触发当前目标交互
      └── void PerformDetection()                       // 每帧视锥检测
```

**检测流程：**
```
每帧 TickComponent:
  PerformDetection()
    → GetPlayerView()                  // 获取玩家视角位置与方向
    → LineTraceSingleByChannel()       // 从视角中心向前射线检测
    → 命中 Actor + 目标有 IInteractableInterface？
         → 更新 CurrentInteractable
         → Broadcast OnInteractableChanged
    → 无命中或目标不可交互？
         → CurrentInteractable = nullptr
```

## 4. 按键管理器

```
UGameInstanceSubsystem
 └── UKeyManager                           // 按键管理器
      ├── UInputAction* InteractAction     // E — 交互
      ├── UInputAction* MoveForwardAction  // W/S — 前后移动
      ├── UInputAction* MoveRightAction    // A/D — 左右移动
      ├── UInputAction* LookAction         // 鼠标 — 视角
      ├── UInputAction* JumpAction         // Space — 跳跃
      ├── UInputMappingContext* DefaultMappingContext
      ├── void ApplyMappingContext(APlayerController*, int32 Priority)
      └── void RemoveMappingContext(APlayerController*)
```

输入动作和映射上下文由 `UKeyManager` 在 `Initialize` 时创建。角色/飞船通过 `ApplyMappingContext` 注册输入。

## 5. 存档管理器

```
UGameInstanceSubsystem
 └── USaveManager                          // 存档管理器
      ├── USaveData* CurrentSaveData       // 当前存档数据
      ├── void SaveToSlot(FString SlotName)   // 保存到指定槽位
      ├── bool LoadFromSlot(FString SlotName) // 从指定槽位读取
      ├── bool DoesSlotExist(FString SlotName) // 检查存档是否存在
      ├── void DeleteSlot(FString SlotName)   // 删除存档
      ├── void AutoSave()                     // 自动存档
      ├── FOnSaveGame OnSave                // 保存委托（各系统绑定）
      └── FOnLoadGame OnLoad                // 读取委托（各系统绑定）

USaveGame
 └── USaveData                            // 存档数据对象
      ├── FPlayerSaveData PlayerData      // 位置/旋转/生命/氧气
      ├── TArray<FItemSaveData> InventoryItems // 物品数据
      ├── FDateTime SaveTimestamp          // 存档时间戳
      └── FString SlotName                 // 槽位名
```

**数据持久化机制：**
- 各系统绑定 `OnSave` / `OnLoad` 委托以参与数据持久化
- `FOnSaveGame` / `FOnLoadGame` 为 `DECLARE_MULTICAST_DELEGATE_OneParam`，支持多播
