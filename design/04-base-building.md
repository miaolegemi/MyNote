# 04 — 基地与飞船建造

## 设计目标

建造系统是游戏的核心表达方式。玩家通过建造来体现进度、个性化和创造力。分为两个层面：移动的飞船（随身携带的家）和静态的基地（扎根的安全港）。

---

## 双层面建造

### 飞船 = 移动基地

飞船是玩家最亲密的建造空间。这是玩家每天看到、使用、依赖的东西。

**核心特征：**
- 有限空间 —— 模块数量和电力预算受限，必须做出取舍
- 功能与舒适的权衡 —— 多装一个货舱还是多装一个居住模块？
- 完全可定制 —— 内部布局由玩家摆放，不是预设模板

### 空间站/地面基地 = 固定基地

基地是长期投资，提供飞船无法承载的大型设施。

**核心特征：**
- 可扩展 —— 理论上没有空间上限（受资源和电力限制）
- 大型设施 —— 大型熔炉、船坞、温室、实验室需要基地空间
- 战略位置 —— 在不同星系建立前哨站作为补给点

---

## 模块化建造系统

### 设计理念

采用网格/插槽式模块建造（参考 Subnautica 的模块拼接），而非自由体素建造（参考 Minecraft）。原因：
- 更易实现美观效果
- 降低建造门槛
- 系统间连接关系更清晰
- 更好优化性能

### 飞船模块类型

| 类别 | 模块示例 | 说明 |
|------|----------|------|
| 核心 | 驾驶舱、反应堆 | 必须存在，飞船才能运作 |
| 推进 | 常规引擎、离子推进器、曲速引擎 | 决定速度、机动性、FTL 能力 |
| 生存 | 生命支持系统、制氧机、水循环器 | 维持船员生存 |
| 功能 | 货舱、扫描仪阵列、采矿激光、精炼舱 | 功能性模块 |
| 防御 | 护盾发生器、点防御炮、电子战模块 | 防御能力 |
| 武器 | 激光炮、导弹架、电磁炮 | 攻击能力 |
| 居住 | 睡眠舱、厨房、医疗舱 | 提升船员舒适度 |

### 基地模块类型

| 类别 | 模块示例 | 说明 |
|------|----------|------|
| 核心 | 指挥中心、主反应堆 | 基地的控制和能源核心 |
| 生产 | 大型熔炉、装配线、化学处理站 | 比飞船版本效率更高 |
| 科研 | 实验室、扫描阵列、数据存档 | 解锁科技、分析异常数据 |
| 生活 | 居住舱、温室、医疗站 | 船员长期驻扎所需 |
| 仓储 | 大型货舱、燃料罐、氧气罐 | 比飞船仓库大得多 |
| 防御 | 炮台、护盾穹顶、防空系统 | 基地防卫 |
| 船坞 | 停泊臂、维修坞、加油管线 | 飞船维护和升级 |

## 生命支持与电网

### 电力系统

```
           ┌──────────┐
           │ 反应堆    │ ← 主电源（核聚变/太阳能/暗物质）
           └────┬─────┘
                │
        ┌───────┴───────┐
        │    电力总线    │ ← 总电力上限
        └───────┬───────┘
                │
    ┌───────────┼───────────┐
    │           │           │
┌───▼───┐  ┌───▼───┐  ┌───▼───┐
│生命支持│  │武器系统│  │生产设施│  ...
└───────┘  └───────┘  └───────┘
```

- 每个模块消耗电力。总消耗不能超过发电量。
- 可以设置电力优先级：生命支持 > 护盾 > 武器 > 生产
- 电力不足时，低优先级系统自动降级或关闭
- 关键系统（生命支持）的断电是极其危险的 —— 制造紧张时刻

### 生命支持

- 氧气、温度、重力（如果有重力发生器）是维持可居住环境的三要素
- 飞船和密封基地模块自动提供密闭环境
- 生命支持系统效率决定最大支持人数
- 模块越多，生命支持负担越大

## 建造流程

1. **获取蓝图** — 通过扫描、研究、探索获取新模块蓝图
2. **收集材料** — 图纸上有明确的材料清单
3. **放置** — 在有效位置放置模块（飞船上的插槽、基地的连接点）
4. **连接系统** — 自动连接电力、管道等（简化操作）
5. **升级** — 已放置的模块可以升级到更高等级

---

## 防御系统

| 防御类型 | 防御对象 | 说明 |
|----------|----------|------|
| 护盾 | 所有伤害 | 消耗电力，可过载强化但会损坏 |
| 点防御 | 导弹、鱼雷 | 自动拦截来袭投射物 |
| 炮台 | 敌舰 | 固定防御火力 |
| 电子战 | 导弹锁定 | 干扰敌人传感器和锁定 |
| 伪装/隐形 | 探测 | 减少被发现的几率（后期科技） |

---

## 建造的满足感来源

- **可见的扩张** — 基地从一间小舱变成大型空间站，过程看得见
- **功能性回报** — 新模块带来新能力，不是纯装饰
- **个性化空间** — 内部装饰、灯光、布局体现玩家审美
- **生存的正反馈** — "上次差点死在深空，这次我装了更好的护盾"
