# 05 — 制作与资源经济

## 设计目标

制作系统是连接"采集"和"建造"的桥梁。资源链要有足够的深度来支持长期目标，但不能复杂到让玩家需要查 Wiki。

---

## 资源层级

```
Tier 1 (常见)          Tier 2 (罕见)          Tier 3 (稀有)          Tier 4 (异星)
─────────────────     ─────────────────     ─────────────────     ─────────────────
铁矿石                 钨矿                   钛矿                   超铀元素
铜矿石                 锂矿                   铂矿                   反物质晶体
硅砂                   金矿                   稀土                   暗物质碎片
碳化合物               超导体前体             量子处理单元           外星科技组件
水/冰                  稀有气体               浓缩燃料               奇异物质
```

**获得来源：**
- **T1** — 起始星系随处可见，小行星带丰富
- **T2** — 需要离开起始星系，特定星球环境产出
- **T3** — 深空区域、危险环境、拆解高级残骸
- **T4** — 极稀有，仅在特殊地点（远古遗迹、黑洞边缘、外星母舰残骸）

## 加工链

资源不是采来即用，需要经过处理：

```
原始资源 → 精炼 → 基础材料 → 制造 → 组件 → 组装 → 成品
   (矿)     ↓       (金属锭)    ↓     (电路板)   ↓    (装备/模块)
         回收 ←──────────────────────────────────┘
```

### 加工设施

| 设施 | 功能 | 电力需求 | 解锁阶段 |
|------|------|----------|----------|
| 基础熔炉 | 矿石 → 金属锭 | 低 | 初始 |
| 化学处理站 | 化合物提取、燃料精炼 | 中 | 早期 |
| 精密加工台 | 材料 → 组件、电路板 | 中 | 中期 |
| 高级装配线 | 组件 → 成品装备 | 高 | 中期 |
| 量子锻造炉 | 异星材料处理 | 极高 | 后期 |
| 回收站 | 成品/残骸 → 回收材料 | 低 | 早期 |

## 制作配方结构

### 配方分类

| 类别 | 示例产物 | 代表性深度 |
|------|----------|------------|
| 消耗品 | 氧气罐、急救包、食物包、燃料棒 | 浅（1-2 步） |
| 工具 | 切割枪、扫描仪、修理工具 | 中（2-3 步） |
| 装备 | 太空服升级、喷气背包、护盾腰带 | 中（2-4 步） |
| 船体模块 | 引擎、反应堆、护盾发生器、货舱 | 深（3-5 步） |
| 基地模块 | 居住舱、实验室、种植舱、防御炮台 | 深（3-5 步） |

### 设计原则

- 消耗品配方简单，常用物品不要太麻烦
- 大件目标物品（新引擎、新反应堆）配方有意义，让完成时有成就感
- 中间产物可复用："电路板"用于多种装备，"合金框架"用于多种建造
- 不需要的材料可以回收，避免仓库堆积无用垃圾

## 工具与耐久度

### 工具等级

每个工具有三个等级：
- **基础级**（初始可制造）— 效率低、能耗高、耐久低
- **工业级**（中期解锁）— 效率中等，需要更好的材料
- **纳米级**（后期解锁）— 最高效率、自我修复、但需要异星材料

### 耐久与维修

- 所有工具和装备使用中消耗耐久
- 耐久耗尽 → 工具不可用但不消失（不像某些游戏直接碎掉）
- 修理消耗材料（通常是制造材料的一部分）
- 高等级工具修理需要对应等级的材料
- 特殊环境下工具损耗加快（高温、腐蚀性大气）

---

## 回收与拆解

- 找到的残骸、废弃设备可以拆解
- 回收效率不是 100%：基础回收站回收约 50% 材料，升级后可达 80%
- 某些异星科技组件不可回收 —— 只能通过探索获得
- 飞船模块更换时，旧模块可以拆解回收大部分材料
- 建造系统中拆除模块全额返还材料（详见 [04 建造文档](04-基地与飞船建造.md) 中的"关键设计决策"），鼓励试错和改造

---

## 自动化

后期解锁自动化生产：
- **管道与传送带** — 连接采矿机到熔炉到仓库
- **无人机** — 自动采集预设范围内的资源
- **自动制造** — 预设配方持续生产，直到材料耗尽或手动停止
- 自动化是可选玩法，不是强制要求
