# 03 — 探索与星图

## 设计目标

探索是游戏的"主菜"。宇宙应该让玩家感到渺小、好奇，以及每次出发都有"万一发现了什么呢"的期待感。

---

## 宇宙结构

### 层级

```
宇宙
 └── 星区 (Sector)         ← 宏观区域，决定大的环境特征
      └── 星系 (System)    ← 一个恒星+其行星系统，主要活动单元
           ├── 恒星
           ├── 行星
           ├── 卫星
           ├── 小行星带
           ├── 空间站/废墟/异常点
           └── 深空区域
```

### 规模设计

- 不是无限宇宙。有限而精心布置的星域优于无限而重复的星域。
- 目标：约 20-30 个可到达的星系，每个星系有独特特征
- 每个星系的兴趣点密度足以支撑 2-5 小时的深入探索

## FTL 航行系统

### 航行模式

| 模式 | 用途 | 速度 | 燃料消耗 | 风险 |
|------|------|------|----------|------|
| 常规推进 | 星系内航行、战斗机动 | 亚光速 | 低 | 最低 |
| 巡航模式 | 跨越行星间距离 | 高亚光速 | 中 | 可能被拦截 |
| 曲速航行 | 跨星系旅行 | 超光速 | 高 | 航行中无法转向，可能撞上未知障碍 |
| 跳跃 | 长距离瞬间到达 | 瞬移 | 极高 | 需要跳跃信标或已知坐标，到达位置有偏差 |

### 航行中的事件

曲速航行不是按一下按钮等加载。航行过程中可能：
- 传感器检测到不明信号 → 可以中断航行去调查
- 遭遇引力异常 → 被拉出曲速
- 引擎过热 → 必须降低速度散热
- 海盗拦截 → 被迫应战或谈判
- 接收到求救信号 → 道德抉择

## 发现系统

### 扫描机制

```
        ┌───────────┐
        │ 被动扫描  │ ← 进入星系自动获取基本信息（恒星、行星数量）
        └─────┬─────┘
              │
        ┌─────▼─────┐
        │ 主动扫描  │ ← 发送扫描脉冲，探测更多细节（资源分布、信号源）
        └─────┬─────┘
              │
        ┌─────▼─────┐
        │ 近距离扫描│ ← 飞近目标，获取详细数据（具体矿物含量、生命迹象）
        └─────┬─────┘
              │
        ┌─────▼─────┐
        │ 实地勘察  │ ← 登陆/出舱，亲身调查
        └───────────┘
```

### 扫描数据的价值

- 完整的星图数据可以卖钱
- 发现首个资源丰富的矿脉 → 先到先得
- 扫描异常信号可能解锁特殊任务链或蓝图
- 玩家的发现可以命名（首个发现者命名权）

## 兴趣点类型

| 类型 | 描述 | 典型奖励 | 典型危险 |
|------|------|----------|----------|
| 废弃空间站 | 被遗弃的旧空间站 | 蓝图、材料、日志 | 保安系统、漏气、残存生物 |
| 外星遗迹 | 未知文明的建筑残骸 | 异星科技、独特蓝图 | 防御系统、能量场、未知生物 |
| 求救信标 | 遇难船只发出的信号 | 道德抉择、可能奖励 | 可能是陷阱（海盗伪装） |
| 资源富集点 | 稀有资源异常集中 | 大量 Tier 3-4 材料 | 环境危险、竞争者 |
| 流浪小行星 | 脱离轨道的小行星 | 随机矿物 | 不稳定轨道、碰撞风险 |
| 虫洞 | 空间裂缝 | 瞬间到达另一星系 | 单向、不稳定、可能关闭 |
| 远古舰坟场 | 大量废弃飞船聚集地 | 回收材料、科技组件 | 太空生物巢穴、辐射 |
| 海盗据点 | 海盗的隐藏基地 | 大量战利品 | 大量敌人、防御系统 |

## 环境危险

| 危险 | 出现环境 | 影响 |
|------|----------|------|
| 辐射带 | 气态巨星附近、脉冲星 | 辐射累积 |
| 陨石雨 | 小行星带、年轻星系 | 船体伤害 |
| 太阳耀斑 | 靠近恒星 | 电子设备故障、护盾击穿 |
| 腐蚀性大气 | 某些行星表面 | 船体/太空服持续受损 |
| 极端温度 | 近恒星/远日行星 | 温控负担 |
| 引力阱 | 黑洞、中子星附近 | 引擎过载、燃料消耗极增 |
| 电磁风暴 | 特殊星云 | 传感器失灵、HUD 故障 |
| 空间裂痕 | 深空异常 | 瞬移至随机位置 |

---

## 星图与导航

- 玩家逐步绘制星图 —— 没去过的地方是空白
- 星图显示已知信息：资源分布、兴趣点标记、危险区域
- 可以放置自定义标记和笔记
- 跳跃航行需要在星图上规划路线
- 某些区域需要特殊钥匙或科技才能进入（如需要高级护盾穿过辐射带）
