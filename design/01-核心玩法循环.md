# 01 — 核心玩法循环

## 设计目标

让玩家持续处于"紧张—放松"的自然呼吸节奏中。没有人工关卡，节奏由玩家自己选择的探索距离和资源管理决定。

---

## 分钟到分钟循环

```
         ┌──────────────┐
         │   在基地/飞船  │  ← 安全区：制造、建造、规划
         │   中整备      │
         └──────┬───────┘
                │
         ┌──────▼───────┐
         │   外出探索    │  ← 风险区：采集、扫描、战斗
         │              │
         └──────┬───────┘
                │
         ┌──────▼───────┐
         │   资源耗尽/   │
         │   飞船受损    │  ← 转折点：必须决定是否返航
         └──────┬───────┘
                │
         ┌──────▼───────┐
         │   返航回安全区 │  ← 回程：燃料管理、可能遭遇追击
         │              │
         └──────┬───────┘
                │
         ┌──────▼───────┐
         │   收获与成长  │  ← 成就感：新蓝图、新材料、新装备
         │              │
         └──────────────┘
```

---

## 典型 1 小时会话流程

1. **登录回顾（~2 分钟）** — 检查飞船状态、补给库存、待办计划
2. **整备规划（~5 分钟）** — 修理受损模块、补充氧气燃料、选择本次探索目标
3. **出发航行（~10 分钟）** — 驾驶飞船前往目标星域，途中扫描信号、规避危险
4. **目标活动（~25 分钟）** — 采集资源、探索废墟、战斗或潜行
5. **返航决策（~5 分钟）** — 评估剩余资源，决定继续深入还是返航
6. **回程航行（~10 分钟）** — 携带收获返航，可能遭遇追击或突发事件
7. **收获整理（~3 分钟）** — 卸货、精炼材料、解锁新蓝图、扩建飞船

## 死亡与重生

### 设计原则

死亡要有代价，但不能有挫败感。玩家应该觉得"是我自己的决策失误"而不是"游戏不公平"。



### 死亡场景与重生方式

死亡后重生取决于玩家是否建造了**休眠仓**（详见 [[04-基地与飞船建造]]）。休眠仓是可选建造设施——建了就多一条命，不建就回安全港。

| 死亡场景 | 有已激活休眠仓 | 无休眠仓 |
|----------|--------------|----------|
| 飞船被毁 | 在**本船休眠仓**重生（如果休眠仓未被摧毁且电力足够完成克隆），丢失随身物品，飞船保留最后一次停靠状态 | 在最近的安全港（空间站/基地）重生，飞船保留最后停靠状态，本次出航所有收获丢失 |
| 登舰/探索中死亡 | 在**最近的已激活休眠仓**重生，丢失随身携带的工具和采集物 | 在飞船舱内/安全港重生，随身工具和采集物丢失 |
| 基地被毁 | 在**基地休眠仓**重生（如果休眠仓未被摧毁），部分模块需重建 | 基地核心可修复，但部分模块需重建 |

**休眠仓约束：**
- 复活过程持续 30 秒，期间休眠仓不可中断（断电/被破坏则克隆失败）
- 复活时休眠仓瞬间消耗大量电力，可能导致其他系统暂时降级
- 休眠仓可被敌人锁定和摧毁——战斗中保护休眠仓是防守关键

### 不做 Roguelike

- 不重置进度
- 不丢失设计图/科技
- 不丢失已建造的永久结构
- 丢失的是"本次出航的收获"和"随身携带的装备"

## 风险回报螺旋（核心驱动）

```
     风险越高的区域 →
┌──────────────────────────────────────┐
│                                      │
│  安全区          过渡区        深空区 │
│  (起始星系)    (已知星域)   (未勘测)  │
│                                      │
│  资源 ★★      资源 ★★★     资源 ★★★★ │
│  危险 ★       危险 ★★      危险 ★★★★ │
│  回去容易      回去需要燃料  可能回不去 │
│                                      │
└──────────────────────────────────────┘
```

**自然推动力：**

- 安全区的低级资源很快不够用 → 玩家自然向外探索
- 每次成功返航获得的新装备/蓝图 → 让下一次能走得更远
- "那个信号看起来很重要，但我的氧气只够返航了" → 制造有意义的抉择时刻

---

## 关键节奏机制

- **氧气计时器** — 最根本的节奏控制器。每次离开安全区探索都有硬上限。玩家必须在氧气耗尽前返回飞船或找到补给点。
- **燃料限制** — 控制探索范围。更远需要更多燃料或更高效引擎。返航必须预留足够燃料。
- **货舱容量** — 控制单次收获上限。贪心多采可能让你超重、飞得慢、油耗更高。
- **飞船磨损** — 每次航行都在消耗飞船模块耐久。不维护会在关键时刻出故障。
