# 07 — 进度与科技树

## 设计目标

进度系统提供一个"永远有下一个目标"的长线驱动。不靠经验值数字往上涨，而是靠看得见的建造和真正的能力解锁。

---

## 进度哲学

### 不做的事情

- **没有角色等级** — 没有"升级到 Lv.15"这回事
- **没有属性点** — 没有"力量+1"、"智力+2"
- **没有经验值** — 不靠杀怪或完成任务获得 EXP

### 做的事情

- **建造即进度** — 建造新模块 = 获得新能力。详见 [04 建造文档](04-基地与飞船建造.md) 中的"建造驱动的进度节点"
- **蓝图即解锁** — 获得新蓝图 = 解锁新的可能性
- **科技树** — 研究解锁新的制作配方和模块
- **操作技能** — 玩家的实际熟练度（真的学会了如何高效对接、如何精确采矿）

---

## 科技树

### 设计

科技树不是线性的，而是以"领域"为单位的分支结构：

```
                    ┌─────────┐
                    │ 基础科技 │
                    └────┬────┘
                         │
       ┌─────┬─────┬─────┼─────┬─────┬─────┐
       │     │     │     │     │     │     │
    ┌──▼──┐┌──▼──┐┌──▼──┐┌──▼──┐┌──▼──┐┌──▼──┐
    │能源 ││推进 ││材料 ││生存 ││武器 ││探测 │
    └──┬──┘└──┬──┘└──┬──┘└──┬──┘└──┬──┘└──┬──┘
       │     │     │     │     │     │     │
    ┌──▼──┐┌──▼──┐┌──▼──┐┌──▼──┐┌──▼──┐┌──▼──┐
    │核聚变││离子 ││纳米 ││高级 ││等离子││量子 │
    │反应堆││推进 ││材料 ││生命 ││武器 ││传感器│
    └─────┘└─────┘└─────┘└─────┘└─────┘└─────┘
```

### 各领域说明

| 领域 | 解锁内容 | 深度 |
|------|----------|------|
| 能源 | 更高功率的反应堆、电池、电力管理 | 决定你所有系统的上限 |
| 推进 | 更快的引擎、高效燃料、高级 FTL | 决定你能去多远 |
| 材料 | 稀有金属加工、复合材料、异星材料 | 决定你能造多好的东西 |
| 生存 | 高级生命支持、抗辐射、医疗 | 决定你在恶劣环境待多久 |
| 武器 | 更强火力、新武器类型、瞄准系统 | 决定你的战斗能力 |
| 探测 | 传感器范围、数据分析、隐形探测 | 决定你发现秘密的能力 |

### 解锁机制

- **科学点数** — 通过扫描、分析文物、做实验获得
- **每个科技需要** — 科学点数 + 前置科技 + 特定材料样本
- **部分科技需要** — 特殊触发条件（如"被辐射伤害过"才能开始研究抗辐射科技）

## 蓝图系统

蓝图有两种获取方式：

### 研究蓝图（科技树解锁）

研究某个科技后自动获得相关蓝图。可靠、可预期。

### 发现蓝图（野外获取）

在探索中扫描残骸、分析文物获得。不可预期，制造惊喜。

- 船体残骸 → 扫描获得飞船模块蓝图片段
- 外星文物 → 分析获得异星科技蓝图
- 数据日志 → 阅读后解锁特殊配方
- 蓝图可以是完整的一张，也可以是碎片（需要收集多个碎片拼合）

## 里程碑系统

里程碑是隐性的"关卡"，用于控制进度节奏：

| 阶段 | 里程碑 | 解锁的内容 |
|------|--------|------------|
| 阶段 1：生存 | 建立第一个基地核心 | 基础生产设施 |
| | 完成第一次 EVA | 出舱工具 |
| | 首次 FTL 跳跃 | 其他星系 |
| 阶段 2：扎根 | 建造第一个高级反应堆 | Tier 2 制造 |
| | 在第二个星系建立前哨站 | 长距离航行 |
| | 击败第一个海盗拦截者 | 战斗装备 |
| 阶段 3：繁荣 | 建造大型空间站 | 高级自动化 |
| | 分析第一个外星文物 | 异星科技线 |
| | 穿越虫洞 | 远宇探索 |
| 阶段 4：大师 | 完全激活远古遗迹 | 终极蓝图 |
| | 直面星噬者 | 终局内容 |
| | 建造戴森群（微型） | 无尽能源 |

## 终局方向

终局不设硬性终点。在"通关"后玩家可以继续建造和探索。提供几个终局目标方向：

1. **远古之谜** — 揭开外星文明消失的真相（主线故事完结）
2. **星际大亨** — 建立横跨多个星系的生产与贸易帝国
3. **终极飞船** — 建造能去到宇宙最远处的传奇飞船
4. **归乡** — 如果地球已经毁灭，寻找新的蓝色星球

玩家可以只完成其中一个方向，也可以全部完成。没有"游戏结束"画面，只有"我做到了"的自我满足。
