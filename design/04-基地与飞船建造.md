# 04 — 基地与飞船建造

## 设计目标

建造系统是游戏的核心表达方式。玩家通过建造来体现进度、个性化和创造力。分为两个层面：移动的飞船（随身携带的家）和静态的基地（扎根的安全港）。

**核心设计原则：建造即进度。** 不靠经验值和属性点来成长，而是靠你亲手造出的每一个模块、每一艘飞船、每一座空间站。造了什么，就拥有了什么能力。

---

## 双层面建造

### 飞船 = 移动基地

飞船是玩家最亲密的建造空间。这是玩家每天看到、使用、依赖的东西。

**核心特征：**
- 有限空间 —— 模块数量和电力预算受限，必须做出取舍
- 功能与舒适的权衡 —— 多装一个货舱还是多装一个居住模块？
- 完全可定制 —— 内部布局由玩家手动摆放，不是预设模板
- 飞船 = 你的装备配置 —— 选择武器、护盾、货舱、探测器的组合定义了你的玩法

### 空间站/地面基地 = 固定基地

基地是长期投资，提供飞船无法承载的大型设施。

**核心特征：**
- 可扩展 —— 理论上没有空间上限（受资源和电力限制）
- 大型设施 —— 大型熔炉、船坞、温室、实验室必须依托基地
- 战略位置 —— 在不同星系建立前哨站作为补给点和快速旅行节点
- 基地 = 你的技能树 —— 建造什么制造站，就解锁什么制造能力

## 模块化建造系统

### 设计理念

采用网格/插槽式模块建造（参考 Subnautica 的模块拼接），而非自由体素建造（参考 Minecraft）。原因：
- 更易实现美观效果
- 降低建造门槛
- 系统间连接关系更清晰
- 更好优化性能

### 连接系统规则

模块之间通过统一的节点网格连接。这是建造的底层"语法"。

**连接节点类型：**

| 节点类型 | 用途 | 说明 |
|----------|------|------|
| 通道节点 | 人员可通行 | 舱室 ↔ 驾驶舱 ↔ 登船口必须形成通路。两个通道节点对齐才能内部穿行 |
| 结构节点 | 大型组件连接 | 引擎、货舱、反应堆等大件挂载。可覆盖在通道节点上（阻断通行） |
| 武器节点 | 武器挂载 | 武器必须安装在专用的武器硬点上 |
| 管线节点 | 电力/管道对接 | 自动连接，用于电力、氧气、燃料传输 |

**连接规则：**
- 每个模块至少需要一个结构节点连接至飞船/基地主体
- 基础模块可 90° 旋转（I 型走廊可横可竖），功能性模块方向固定
- 不强制对称 —— 起落架可以全在左侧，引擎可以不对等分布（太空不需要空气动力学）
- 模块之间必须形成从驾驶舱到登船口的**连通路径**（飞船），否则建造验证不通过

**内部布局（玩家实际行走的空间）：**
- 玩家以第三人称在飞船内部行走，亲自穿过自己建造的走廊、舱室、梯子
- 舱室之间的门和梯子由玩家手动放置（吸取 Starfield 自动生成经常不合理的教训）
- 内部布局直接决定行走效率和紧急情况下的逃生速度——布局不只是美观，是玩法
- 系统提供智能辅助提示：标注"这里放门会形成死路"、"这里建议放梯子连接上下层"
- 提供内部布局预览，确认后一次性生成通道

### 舱内设施系统

起居舱内部是空白的可步行空间。玩家在舱内**自由放置**功能设施，唯一约束是设施的物理尺寸——放得下就能摆，放不下就不能摆。

#### 设施类型

| 类别 | 设施示例 | 说明 |
|------|----------|------|
| 制造 | 基础制造台、精密制造台、弹药装填台 | 在船上制造工具、消耗品和弹药 |
| 存储 | 储物柜、武器架、冷藏箱 | 扩大船上存储空间 |
| 医疗 | 急救站、手术台、减压治疗舱 | 治疗伤病、移除状态效果 |
| 生活 | 睡眠舱、厨房单元、娱乐终端 | 恢复疲劳、提升船员士气 |
| 研究 | 分析终端、样本处理台 | 就地分析扫描数据、处理异星样本 |
| 工程 | 维修终端、电力调节器、灭火系统 | 增强飞船系统性能或提供被动增益 |

#### 放置规则：三维体积约束

舱内设施建造**不设槽位**。设施占用三维空间，最小单位为 **0.5m 立方体**。放得下就能摆，三维碰撞则不允放置。

```
工程舱（内部 4×3×3 立方体网格）
═══════════════════════════════════════════
  俯视图（地板 XY）         侧视图（XZ，沿舱壁看）
  
  ┌──────────────────┐      ┌──────────────────┐
  │  ┌──────────┐    │      │ 3  ┌──────────┐  │  ← 天花板高度 3
  │  │  精密    │░░░░│      │   │  精密    │  │
  │  │  制造台  │░░░░│      │ 2 │  制造台  │  │    精密制造台 = 2×3×2
  │  │  2×3×2  │░░░░│      │   │  2×3×2  │  │    (宽×深×高)
  │  └──────────┘░░░░│      │ 1 │          │  │
  │  ┌────┐┌────┐░░░░│      │   └──────────┘  │    储物柜 = 1×1×2
  │  │储物││储物│░░░░│      │ 0 ────────────── │    (可堆叠)
  │  │1×1 ││1×1 │░░░░│      └──────────────────┘
  │  │ ×2 ││ ×2 │░░░░│
  │  └────┘└────┘░░░░│      ░░░░ = 必须保留的通行空间
  │  ░░░░░░░░░░░░░░░░│      (≥1 格宽 × 角色高度)
  └──────────────────┘
```

**核心规则：**

| 规则 | 说明 |
|------|------|
| **三维占用** | 每个设施定义 宽×深×高（以 0.5m 立方体为单位）。设施的三维包围盒不重叠即可放置 |
| **贴舱壁** | 大型设施（如制造台 2×3×2）必须至少有一个面贴舱壁（墙壁/地板/天花板），不能悬在空中。小型设施（1×1×1）可自由放置 |
| **可通行性** | 放置后必须保留至少 1 格宽 × 角色身高（通常 2 格高）的连续三维通道，从该舱室的每一个门通向其他所有门 |
| **垂直叠放** | 小型设施可叠放在其他设施上方（如储物柜堆叠：1×1×2 + 1×1×2 = 1×1×4），上方设施的底面支撑面必须完全落在下方设施的顶面上 |
| **电力预算** | 设施耗电计入飞船总电力。超限可放置但处于断电状态（不可用） |

#### 舱室内部三维空间

每个舱室有完整的三维内部尺寸（宽 × 深 × 高，以立方体为单位）：

| 舱室类型 | 内部三维空间 | 设计意图 |
|----------|-------------|----------|
| 工程舱 | 4×3×3 | 宽敞，能容纳 2×3×2 的大型制造设备 |
| 实验室 | 3×3×3 | 中等，够放一个研究大件 |
| 医疗舱 | 3×3×3 | 同实验室 |
| 居住舱 | 4×4×3 | 最大体积，生活设施可堆叠利用垂直空间 |
| 货舱 | 3×4×2 | 高度受限（天花板低），无法放高建设施，但可沿墙密集排列 |
| 多功能舱（走廊） | 1×4×3 | 狭长，仅能贴壁放小型设施且必须保证通道 |
| 驾驶舱 | 3×2×3 | 驾驶位固定占用 2×1×2 的中心区域 |

> 驾驶位是固定设施——不消耗玩家放置额度，但减少了驾驶舱剩余可用空间。

#### 设施三维尺寸分级

| 尺寸等级 | 典型体积（宽×深×高） | 电力消耗 | 示例 |
|----------|---------------------|----------|------|
| 微型 | 1×1×1 | 极低 | 灭火喷头（天花板安装）、壁灯、传感器 |
| 小型 | 1×1×2 | 低 | 储物柜、睡眠舱、急救站、分析终端 |
| 中型 | 1×2×2 或 2×1×2 | 中 | 基础制造台、弹药装填台、减压治疗舱、电力调节器 |
| 大型 | 2×3×2 或更大 | 高 | 精密制造台（2×3×2）、手术台（2×2×2） |
| 超大型 | 3×3×3 | 极高 | 纳米制造台（占用整个小型舱室的体积） |

**垂直空间的利用：** 低矮设施（高 1）可放在桌面/架子上；高建设施（高 3）需要舱室有足够天花板高度。这让舱室的高度差异有了实际意义——货舱只能放矮柜，工程舱能放高耸的制造台。

#### 舱内设施建造流程

```
1. 已建造起居舱模块
       ↓
2. 玩家走到舱室内部，进入建造模式（同飞船建造器，切换到"设施模式"）
       ↓
3. 从设施列表中选择 → 在舱内三维空间中移动半透明预览
   （绿色 = 可放置，红色 = 不可放置——三维碰撞/阻断通道/高度不足/支撑不足）
       ↓
4. 确认 → 扣材料 → 设施出现（小型即时，大型有短暂建造动画）
       ↓
5. 玩家走到设施前 → 按交互键使用
```

**与飞船模块建造的关系：**
- 设施建造使用**同一套材料经济**（铁锭、电路板等），但配方较轻量
- 设施可单独拆除，材料全额返还（同飞船模块的拆除规则）
- 更换舱室模块时，该舱室内的设施自动拆卸并退还材料（避免 Starfield "改装丢装饰" 的挫败感）
- 编辑舱室模块布局时（添加/移动舱室），设施保留在原舱室内。删除舱室则设施退还

#### 飞船 vs 基地的设施放置

| 对比维度 | 飞船设施 | 基地设施 |
|----------|----------|----------|
| 主要约束 | 舱室三维空间紧凑 | 舱室三维空间更宽敞 |
| 高级设施 | 受反应堆电力上限限制 | 可达最高等级（基地有更大反应堆） |
| 放置规则 | 三维体积约束，同一套规则 | 同左 |
| 拆除 | 材料全额返还 | 材料全额返还 |

飞船和基地使用**同一套设施**和**同一套三维放置规则**。差别只在于三维空间大小和电力——飞船的紧凑是物理上的自然约束，基地的宽敞让你能铺开更多。

```
飞船的约束链：
  反应堆等级 → 电力上限 → 能同时激活多少设施
  舱室三维体积 → 能塞下多少设施（长×宽×高全维度约束）
  你想带制造+研究+医疗 → 需要工程舱+实验室+医疗舱 → 飞船更大 → 需要更大反应堆
```

不需要槽位或专属限制——三维空间和电力的物理约束已经足够形成有意义的取舍。

### 飞船模块类型

| 类别 | 模块示例 | 说明 | 来源风格 |
|------|----------|------|----------|
| 核心 | 驾驶舱、反应堆 | 必须存在，飞船才能运作 | 各派系均有 |
| 推进 | 常规引擎、离子推进器、曲速引擎 | 决定速度、机动性、FTL 能力 | 流浪者改装（高机动/低耐久）、企业标准（稳定/昂贵） |
| 生存 | 生命支持系统、制氧机、水循环器 | 维持船员生存 | 联盟制式（均衡）、拾荒者拼装（便宜/不稳定） |
| 功能 | 货舱、扫描仪阵列、采矿激光、精炼舱 | 功能性模块 | 企业精工（高效/昂贵） |
| 防御 | 护盾发生器、点防御炮、电子战模块 | 防御能力 | 联盟制式（可靠）、企业精工（高性能） |
| 武器 | 激光炮、导弹架、电磁炮 | 攻击能力 | 各派系风格各异 |
| 居住 | 睡眠舱、厨房、医疗舱 | 提升船员舒适度和士气 | 自由殖民者（实用温馨）、企业（标准冷峻） |

### 基地模块类型

| 类别 | 模块示例 | 说明 |
|------|----------|------|
| 核心 | 指挥中心、主反应堆 | 基地的控制和能源核心 |
| 生产 | 大型熔炉、装配线、化学处理站 | 比飞船版本效率更高，批量生产 |
| 科研 | 实验室、扫描阵列、数据存档 | 解锁科技、分析异常数据——建造此模块才能使用科技树研究 |
| 生活 | 居住舱、温室、医疗站 | 船员长期驻扎所需 |
| 仓储 | 大型货舱、燃料罐、氧气罐 | 比飞船仓库大得多，战略储备 |
| 防御 | 炮台、护盾穹顶、防空系统 | 基地防卫，等级决定可安全驻扎的星域 |
| 船坞 | 停泊臂、维修坞、加油管线 | 飞船维护、修理、模块升级——建造此模块才能升级飞船模块 |

### 飞船等级系统

飞船不按单一数值分等级，而是按反应堆等级决定可用零件的级别：

| 等级 | 反应堆类型 | 典型乘员 | 航程 | 解锁条件 |
|------|-----------|----------|------|----------|
| 轻型 | 基础核聚变 | 1-2 人 | 短途（单星系内） | 初始 |
| 中型 | 增强核聚变 | 3-5 人 | 中程（相邻星系） | 驾驶熟练度 + 蓝图 |
| 重型 | 暗物质反应堆 | 6+ 人 | 长途（跨星区） | 高级驾驶熟练度 + 稀有蓝图 |

等级带来清晰的目标感："我要换一台中型反应堆才能装得下那个曲速引擎和护盾。"

## 建造约束与验证

### 飞船建造验证

建造完成后必须通过飞行检查才能保存。分为硬性错误和软性警告：

**硬性错误（红色，必须修复才能保存）：**

| 约束 | 规则 | 设计意图 |
|------|------|----------|
| 必备模块 | 驾驶舱(1)、反应堆(1)、引擎(≥1)、生命支持(≥1)、登船口(1)、对接器(1) | 确保飞船基本功能完整 |
| 电力预算 | 所有模块总功率消耗 ≤ 反应堆输出功率 | 不能装载超出能源能力的设备 |
| 质量/推力比 | 飞船总质量 ≤ 引擎总推力 × 系数，不达标不可起飞 | 太重就飞不起来 |
| 起落架承重 | 1 起落架支撑 N 吨，总承重 ≥ 飞船总质量 | 降落时不会摔坏 |
| 登船口位置 | 必须在飞船外侧边缘，且无遮挡 | 物理上能进出 |
| 连通路径 | 从驾驶舱到登船口必须存在可通行的通道连接 | 船内能走到各个区域 |
| 尺寸限制 | 长/宽/高 ≤ 最大尺寸（具体数值待定） | 不能无限堆叠 |

**软性警告（黄色，可保存但不推荐）：**

| 警告 | 说明 |
|------|------|
| 无护盾 | 飞船在战斗中极度脆弱 |
| 无武器 | 遭遇敌人时只能逃跑 |
| 无医疗舱 | 船员受伤无法在船上治疗 |
| 引擎功率接近临界值 | 机动性极差，转向迟缓 |
| 生命支持接近上限 | 稍有损耗就可能缺氧 |

### 基地建造约束

参考 Subnautica 的结构完整性系统，基地面临不同的约束：

| 约束 | 规则 | 参考来源 |
|------|------|----------|
| 生命支持负担 | 每个密封模块消耗生命支持容量。制氧机/温控器的总容量 ≥ 所有模块的消耗总和。超限时基地无法维持可居住环境 | 类似 Subnautica Hull Integrity |
| 电力上限 | 同飞船的电力预算规则 | |
| 地基要求 | 大型模块（船坞、大型熔炉）必须建在地基上。地基需要平坦地形 | |
| 环境加固 | 高危环境（辐射行星、极端温度、腐蚀性大气）需要额外的环境加固模块，否则基地模块持续受损 | |
| 扩张惩罚 | 基地越大，维持它所需的电力和生命支持越多——形成自然的"不无限扩张"约束 | |

## 生命支持与电网

### 电力系统

```
           ┌──────────┐
           │ 反应堆    │ ← 主电源（核聚变/太阳能/暗物质）
           └────┬─────┘
                │
        ┌───────┴───────┐
        │    电力总线    │ ← 总电力上限
        └───────┬───────┘
                │
    ┌───────────┼───────────┐
    │           │           │
┌───▼───┐  ┌───▼───┐  ┌───▼───┐
│生命支持│  │武器系统│  │生产设施│  ...
└───────┘  └───────┘  └───────┘
```

- 每个模块消耗电力。总消耗不能超过发电量。
- 可以设置电力优先级：生命支持 > 护盾 > 武器 > 生产
- 电力不足时，低优先级系统自动降级或关闭
- 关键系统（生命支持）的断电是极其危险的 —— 制造紧张时刻
- 战斗中可动态调配电力（从引擎抽电到护盾，或从护盾抽电到武器）—— 参照 FTL 的紧张决策

### 生命支持

- 氧气、温度、重力（如果有重力发生器）是维持可居住环境的三要素
- 飞船和密封基地模块自动提供密闭环境
- 生命支持系统效率决定最大支持人数
- 模块越多，生命支持负担越大

## 建造流程

### 完整流程

```
1. 获取蓝图 ────→ 2. 收集材料 ────→ 3. 建造模式 ────→ 4. 放置模块
     ↑                                                    │
     │                                                    ↓
     └──────────────────── 7. 扩建/改造 ←── 6. 收获使用 ←── 5. 验证保存
```

1. **获取蓝图** — 通过扫描残骸、研究科技树、探索遗迹获取新模块蓝图
2. **收集材料** — 蓝图上有明确的材料清单，建造界面实时显示材料缺口
3. **进入建造模式** — 在飞船技师/基地终端进入。有两种模式：
   - **快速升级**：同品牌/同型号零件的直接替换（简单快捷）
   - **自由建造**：完整的模块增删改（深度定制）
4. **放置模块** — 模块自动吸附到有效连接点。界面实时显示：材料消耗、电力变化、质量变化
5. **验证保存** — 飞行检查自动运行，标注错误（红色）和警告（黄色）。解决所有错误后才能确认并扣材料
6. **收获使用** — 新模块带来新能力，直接影响后续的探索、战斗、生产
7. **扩建/改造** — 拆除、替换、升级已有模块

### 关键设计决策

| 设计点 | 决策 | 原因 |
|--------|------|------|
| 拆除退款 | 全额返还材料 | 零惩罚试错，降低建造心理门槛 |
| 蓝图模式 | 有 | 可以先规划整体布局，确认后一次性建造。避免"材料都花了才发现不合适" |
| 建造时间 | 小型模块即时，大型模块有建造进度条 | 大型模块（船坞、高级反应堆）的等待时间制造期待感 |
| 模块升级 | 同一位置可直接升级（Mark I → Mark II） | 不需要拆除重建，降低升级阻力 |
| 改装影响 | 内部装饰保留，仅受影响的区域重置 | 避免 Starfield"改一个零件全船装饰清空"的挫败感 |
| 撤销功能 | 建造模式内支持撤销/回退 | 允许玩家大胆尝试，不满意可以回退 |

## 防御系统与建造联动

防御不是"装更多炮"，而是"装什么才能去那个危险但资源丰富的地方"。

### 防御-建造关联

| 防御系统 | 建造要求 | 解锁的探索区域 |
|----------|----------|---------------|
| 基础护盾 | 护盾发生器 + 反应堆电力余量 | 安全星系、低威胁区域 |
| 高级护盾（2级+） | 高级护盾发生器 + 中型以上反应堆 | 辐射带、高威胁星系 |
| 点防御炮 | 点防御模块 + 武器电力预算 | 导弹/鱼雷威胁区域 |
| 电子战模块 | 电子对抗套件 + 传感器阵列 | 海盗活跃区域 |
| 隐形/伪装 | 隐形模块（高耗电）+ 高级反应堆 | 深空高危区域、企业禁地 |

### 基地防御等级

| 威胁环境 | 最低防御配置 | 说明 |
|----------|-------------|------|
| 安全星系 | 无防御 | 起始区域，没有敌对威胁 |
| 边疆星系 | 基础炮台 | 偶尔的海盗侦察 |
| 资源富集区 | 炮台 + 基础护盾 | 竞争者可能来犯 |
| 深空前哨 | 护盾穹顶 + 多炮台 | 远离文明，孤立无援 |
| 敌对领地 | 全套防御 | 在敌人势力范围内扎根 |

**设计意图：** 防御等级不是数值比拼，而是建造的"门槛"——想在那个富矿星系建前哨站？先确保你的防御能撑住。

## 建造驱动的进度节点

建造 IS 进度。以下节点直接由建造触发，不靠等级或经验值：

| 建造节点 | 解锁的能力 | 影响的玩法 |
|----------|-----------|-----------|
| 第一个基础反应堆 | 电力工具、基础制造台 | 制造系统启动 |
| 第一个分析实验室（基地） | 科技树研究功能 | 可投入科学点数研究新科技 |
| 第一个船坞（基地） | 飞船模块升级（不只是替换） | 可在已有模块基础上升级而非整件更换 |
| 第一个高级熔炉 | Tier 2 材料加工 | 解锁中级装备和模块制造 |
| 第一个曲速引擎（飞船） | 跨星系 FTL 航行 | 探索范围从单星系扩展到多星系 |
| 第一个高级生命支持（飞船） | 深空/高危环境生存 | 可进入辐射带、极端温度区域 |
| 第一个量子锻造炉（基地） | Tier 4 异星材料处理 | 终局装备制造 |
| 激活外星遗迹 | 异星科技蓝图线 | 全新的独特模块和能力 |

## 建造的满足感来源

- **修复的满足感** — "从一艘捡来的破船开始，修好每一条裂缝、换掉每一个故障模块，最终它焕然一新"（参照 Subnautica 用修理工具补裂缝的体验）
- **从零成长的满足感** — 基地从单个舱室变成多层空间站，过程的每一步都看得见
- **功能解锁的满足感** — "造了分析实验室，终于能研究那个捡了很久的异星文物了"——每个新模块带来可立刻使用的新能力
- **配装成功的满足感** — "上次差点死在辐射带，这次装了抗辐射护盾，从容飞过"——建造是对过去失败的直接回应
- **个性化表达的满足感** — 外观涂装、内部布局、灯光氛围，这是属于"我"的空间
- **生存反证的满足感** — "三个月前我连氧气都不够用，现在我有一支舰队"——建造物本身就是成长的纪念碑

## 需要避免的建造挫败感

| 挫败感 | 防范措施 |
|--------|----------|
| "我找不到哪里出错了" | 建造验证高亮具体问题模块，逐条列出修复建议 |
| "我就动了一个模块，整个船都散架了" | 支持分组操作，移动一个模块不会导致其他模块自动脱落（除非连接节点断裂） |
| "我想试一个大胆的布局，但怕拆了装不回去" | 蓝图模式允许先规划；建造支持撤销/回退 |
| "材料差一点但看不到缺什么" | 建造界面实时显示材料清单和缺口数量 |
| "内部走廊像迷宫" | 门和梯子由玩家手动放置，智能辅助提示避免死路 |
| "造了大基地但没什么用" | 每个大型模块都有明确的功能回报（详见建造驱动的进度节点） |
| "想造新东西但蓝图去哪找不知道" | 蓝图来源标注在科技树中（研究解锁/探索发现），给玩家可追踪的获取路径 |

## 建造自由度边界（明确表态）

- **不强制对称** —— 起落架可以只在左侧，引擎可以不对等分布（真实太空不需要空气动力学）
- **不强制美学** —— 玩家可以造出丑陋但实用的飞船
- **不强制最优解** —— 允许玩家为了好看牺牲效率
- **有边界** —— 必须在建造约束（电力、质量、尺寸、连通性）内发挥创意。边界本身就是创造力的框架
