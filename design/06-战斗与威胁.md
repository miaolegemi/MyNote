# 06 — 战斗与威胁

## 设计目标

战斗不是游戏的主要驱动力，但必须是体面的、有存在感的。玩家应该害怕战斗，而不是渴望战斗。同时，偶然的危险遭遇让宇宙感觉真实和不可预测。

---

## 威胁分类

### 一、环境威胁（详见 03 探索文档）

环境是最常见、最持久的威胁。很多时候"打败环境"就是战斗。

### 二、宇宙生物

| 生物 | 出现区域 | 威胁等级 | 行为模式 |
|------|----------|----------|----------|
| 小行星蠕虫 | 小行星带 | 低 | 领地性，守矿 |
| 深空鳐鱼 | 深空 | 中 | 迁徙性，被引擎噪音吸引 |
| 太空水母群 | 星云 | 中 | 浮动，触碰伤害，集群行动 |
| 虚鲸 | 深空 | 高 | 无视玩家除非被攻击，但靠近会受引力拉扯 |
| 巢穴母体 | 废弃空间站/废墟 | 极高 | 领地性极强，召唤子嗣 |
| 星噬者 | 极深空 | Boss | 极少见，主动猎食飞船，被击败掉落极稀有材料 |

**设计哲学：** 宇宙生物不是"野怪"。它们是生态系统的一部分。大部分情况下，绕开它们比战斗更明智。

### 三、人类威胁

| 类型 | 说明 | 行为 |
|------|------|------|
| 海盗 | 掠夺者，以抢劫为生 | 拦截、索要货物、不满足即攻击 |
| 拾荒者 | 比你更穷的幸存者 | 通常不主动攻击，但会偷你的采矿点 |
| 佣兵 | 受雇于某个派系 | 被派来追杀你（如果你得罪了某派系） |
| 疯狂的幸存者 | 深空待太久的受害者 | 不理性、难以预测、有时值得同情 |
| 企业安保 | 大企业的私人武装 | 守卫企业资产，非法入侵则开火 |

### 四、远古威胁

| 类型 | 说明 |
|------|------|
| 远古防御系统 | 外星遗迹中的自动防御，仍然运转 |
| 纳米虫群 | 失控的外星纳米机器，分解一切接触的物体 |
| 量子残影 | 不确定是幻觉还是真实的存在，出现在高辐射区 |

## 舰船战斗

### 战斗模型

舰船战斗是"系统管理战"而非"射击战"：

- **不是 FPS 瞄准。** 锁定目标后武器自动追踪。玩家管理的是：分配电力到哪个系统、选择什么武器、瞄准哪个子系统。
- **核心决策：** 攻击敌人的引擎（阻止逃跑）、武器（解除威胁）、护盾（快速击杀）还是反应堆（一击必杀但最难命中）？

### 武器类型

| 武器 | 优点 | 缺点 |
|------|------|------|
| 激光炮 | 精确、无弹道延迟 | 能耗高、受护盾克制 |
| 电磁炮 | 穿透护盾、高伤害 | 弹药有限、需要瞄准、弹道有延迟 |
| 导弹 | 追踪、高伤害 | 可被点防御拦截、弹药昂贵 |
| 离子炮 | 瘫痪系统而不损坏船体 | 低伤害、短射程 |
| 鱼雷 | 极高伤害、范围爆炸 | 速度慢、弹药极少、可被拦截 |

### 护盾与防御

| 系统 | 效果 |
|------|------|
| 能量护盾 | 吸收伤害直到过载，消耗电力 |
| 船体装甲 | 护盾击穿后的被动减伤 |
| 点防御炮 | 自动摧毁来袭导弹和鱼雷 |
| 电子对抗 | 干扰敌人锁定，增加敌人命中难度 |
| 紧急机动 | 瞬间加速闪避，消耗大量燃料 |

### 舰船战斗的"有意思的抉择"

- 引擎动力分配给护盾还是武器？
- 现在撤退还来得及，但燃料够不够跑？
- 敌船引擎已瘫痪，是登船掠货还是直接击毁？
- 对方发出投降信号 —— 相信还是陷阱？

## 登舰与舱内战斗

### 登舰战斗（Boarding）

舰船战斗可以以登舰收尾——瘫痪敌船引擎后对接，亲身进入敌船：

- **进入方式：** 破坏敌船引擎 → 对接器对接 → 切割/破解舱门 → 进入敌船内部
- **敌船内部：** 敌船也是由模块拼接而成，内部布局取决于敌人的建造方式。走廊、舱室、拐角都是交火点
- **武器种类：** 手枪、步枪、霰弹枪、切割工具（近战）
- **弹药稀缺：** 弹药是资源，不是无限补给。登舰前需权衡弹药储备
- **目标：** 击杀/制服船员、夺取货舱物资、占领飞船（可拖回基地拆解或自用）
- **风险：** 敌人可能设伏、可能在关键时刻启动自毁、你的飞船在对接期间处于脆弱状态

### 遗迹/空间站内战斗

进入废弃空间站、外星遗迹等兴趣点时，同样以第三人称步行探索和战斗：

- 环境和敌人类型决定战斗风格（狭窄走廊 vs 开阔大厅、机器人 vs 生物）
- 护甲受损是持续威胁——战斗中护甲破裂可能暴露于有毒大气或真空
- 低重力/零重力环境下的战斗：后坐力会推动角色，近战比远程更安全

**设计倾向：** 舱内和遗迹战斗以潜行和规避为主，正面交火是消耗资源的最后选择。

---

## 潜行与规避

### 潜行机制

- **信号管理：** 降低引擎输出、关闭非必要系统 → 减少传感器信号 → 更难被发现
- **环境掩护：** 躲在小行星后、飘浮在残骸中、藏在星云里
- **静默航行：** 关闭主动扫描和引擎，靠惯性滑行

### 逃脱选项

- 引擎过载冲出危险区域（但会损坏引擎）
- 投放诱饵（热源诱饵、信号诱饵）
- 紧急曲速（不稳定、可能偏离目的地几万公里）

## Boss 级遭遇

| 遭遇 | 触发 | 体验目标 |
|------|------|----------|
| 星噬者 | 进入极深空区域 | 恐怖：被猎食的感觉，必须逃跑或在极端不利条件下战斗 |
| 海盗无畏舰 | 得罪海盗派系到一定程度 | 史诗：以寡敌众，利用环境和小行星带周旋 |
| 远古守护者 | 探索最深的遗迹 | 谜题+战斗：找到机制弱点，不是堆伤害 |
| 企业追捕舰队 | 窃取企业核心机密后 | 被狩猎：持续被追捕，直到逃出他们的势力范围 |

## AI 行为框架

| 行为类型 | 描述 |
|----------|------|
| 领地防御 | 不主动追击远离领地的玩家，只在领地内攻击 |
| 劫掠 | 评估目标价值 vs 自身损伤，不合算就撤退 |
| 猎食 | 追踪弱小信号，避开强大信号 |
| 复仇 | 派系好感降低到一定程度后派兵追杀 |
| 恐惧 | 受重伤后撤退，呼叫增援 |
