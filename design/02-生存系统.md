# 02 — 生存系统

## 设计目标

生存系统提供持续的低频压力，迫使玩家做规划与取舍。它不是为难而难，而是制造"我算好了，刚好够"的满足感。

---

## 生存指标概览

### 一级指标（直接致死）

| 指标 | 作用 | 耗尽后果 | 恢复方式 | 视觉反馈 |
|------|------|----------|----------|----------|
| 氧气 | 船舱/空间站生命支持 | 窒息死亡（全船人员） | 返回密封环境；制氧机；氧气罐 | 视野边缘结霜、呼吸声加重 |
| 生命值 | 抵御物理伤害 | 死亡 | 医疗包、休息、高级医疗站 | 屏幕边缘红色、行动迟缓 |

### 二级指标（间接或累积致死）

| 指标 | 作用 | 耗尽后果 | 恢复方式 | 视觉反馈 |
|------|------|----------|----------|----------|
| 食物/水 | 维持身体机能 | 生命值持续下降、行动迟缓、视野模糊 | 食物与水合成、温室种植 | 胃鸣声效、屏幕轻微模糊 |
| 温度 | 防止过热/失温 | 持续生命值下降 | 太空服温控、飞船温控系统、篝火级应急热源 | 极端冷：结霜 | 极端热：热浪扭曲 |
| 辐射 | 累积伤害 | 生命上限降低、随机病症 | 抗辐射药、减压舱、时间自然代谢 | 盖革计数器声效、噪点 |

### 三级指标（系统级压力）

| 指标 | 作用 | 耗尽后果 | 恢复方式 |
|------|------|----------|----------|
| 飞船电力 | 驱动所有船载系统 | 系统停摆（生命支持、引擎、护盾依次关闭） | 太阳能板、核反应堆、燃料发电机 |
| 模块耐久度 | 单个系统模块的健康度 | 该模块效率下降或完全故障 | 维修工具、替换零件、完全重建 |
| 船体完整性 | 飞船整体的结构健康 | 漏气、爆炸、解体 | 船体修复模块、空间站维修坞 |

## 伤病系统

### 伤情分级

| 等级 | 示例 | 影响 | 治疗 |
|------|------|------|------|
| 轻伤 | 擦伤、轻微冻伤 | 移速微降 5% | 绷带、急救包 |
| 中等伤 | 骨折、二度烧伤 | 移速大降 20%、某些操作不可用 | 医疗站、手术套件 |
| 重伤 | 内脏损伤、船体破裂导致的减压暴露 | 移速减半、生命值上限降低、持续掉血 | 高级医疗站、稀有药物 |
| 永久伤 | 辐射致突变、肢体丧失 | 永久性属性改变 | 仿生义体（后期科技） |

### 船体破损与减压

飞船遭遇战斗或撞击导致船体破损时的头号威胁：
- 舱壁破裂 → 所在舱室急速失压 → 氧气极速流失，需在数秒内转移到密封舱段或关闭防水门
- 防水门自动/手动关闭，隔离受损舱段
- 修复工具：船体修复模块、紧急密封套件

## GAS 属性集与效果

### 属性集定义

生存系统使用 UE Gameplay Ability System 管理所有属性：

```
UVitalAttributeSet                  // 一级指标（直接致死）
 ├── Oxygen                         // 0-100，氧气剩余
 └── Health                         // 0-100，生命值

UConditionAttributeSet              // 二级指标（间接或累积致死）
 ├── Food                           // 0-100
 ├── Water                          // 0-100
 ├── BodyTemp                       // 摄氏度，正常 37
 └── Radiation                      // 累积值，达阈值触发效果
```

### GameplayEffect 定义的状态效果

每个状态效果是一个 `UGameplayEffect`（GE），施加到角色的 `UAbilitySystemComponent`：

| GE 名称 | 类型 | 触发条件 | 施加效果 | 移除条件 |
|---------|------|----------|----------|----------|
| `GE_Hypothermia` | Duration | `BodyTemp < 30` | `MoveSpeedModifier = -0.2`，`OperationDelayModifier = +0.3` | `BodyTemp >= 35` |
| `GE_Hyperthermia` | Duration | `BodyTemp > 42` | `ScreenBlurScale = 0.5`，`HealthChangePerSecond = -1` | `BodyTemp <= 38` |
| `GE_Radiation_I` | Infinite | `Radiation > Threshold_1` | `MaxHealthModifier = -0.1` | 使用抗辐射药移除 |
| `GE_Radiation_II` | Infinite | `Radiation > Threshold_2` | `MaxHealthModifier = -0.25` | 使用高级抗辐射药 |
| `GE_Radiation_III` | Infinite | `Radiation > Threshold_3` | `MaxHealthModifier = -0.5` | 使用减压舱治疗 |
| `GE_Hypoxia` | Duration | `Oxygen < 20` | `ScreenWidenessModifier = -0.3`，`OperationPrecisionModifier = -0.2` | `Oxygen >= 30` |
| `GE_Decompression` | Duration | 船体快速失压 | `AudioMuffleScale = 0.8`，`ScreenShake = 0.5` | 30 秒自动过期 |
| `GE_Fatigue` | Duration | 长时间未休息 | `AllOperationSpeedModifier = -0.15` | 在睡眠舱/床休息 |

### GameplayTag 标记

| Tag | 用途 |
|-----|------|
| `State.Dead` | 角色已死亡 |
| `State.Downed` | 倒地待救 |
| `State.Stunned` | 眩晕（不能行动） |
| `State.Invulnerable` | 无敌（复活后短暂保护） |
| `State.InSealedEnvironment` | 在密封环境内（O2 消耗降低） |
| `State.InVacuum` | 在真空中（O2 快速消耗） |
| `Damage.Physical` / `Damage.Radiation` / `Damage.Thermal` | 伤害类型标签，用于抗性计算

## UI/UX 反馈原则

- **不靠 UI 数字，靠感官** — HUD 尽量精简。用声音（呼吸加重）、视野效果（边缘结霜）、角色动作（发抖）传达状态。
- **关键信息始终可见** — 氧气剩余、生命值这两个一级指标始终在 HUD 上，其余按需显示。
- **三级警告机制** — 注意（视觉提示）→ 警告（声音警报）→ 紧急（屏幕效果 + 声音狂响），不让玩家死得不明不白。
